# Kits de bateria e efeitos

Os kits Frequency303 usam teclas consecutivas a partir do número MIDI 36; use os números, pois o nome da oitava varia entre programas. One shots individuais são transponíveis, com afinação original em MIDI 60. Loops SK5 permanecem WAV para arrastar como áudio no Live; não há sincronização automática de tempo no Instro.
